# Módulos de producto

Cada función futura de Tribuus debe vivir en una carpeta propia y exponer una API pequeña. Las rutas en `src/app` solo componen pantallas; el acceso a red, dispositivo o persistencia se implementa detrás de los contratos de `src/services`.

Módulos previstos: autenticación, onboarding, comunidades, publicaciones, eventos, recomendaciones, seguridad, mercado, mapa, organizaciones, voluntariados, perfil, emergencias y notificaciones.
